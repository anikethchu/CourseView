# CourseView

CourseView is a full-stack course discovery platform that helps students explore courses and make informed academic decisions. It combines an LLM-powered course recommender grounded in university policy PDFs with student discussions and a fine-tuned RoBERTa comment filter for identifying biased content.

**Features**
- Course recommendations informed by university policy documents.
- Student comments and discussions about courses.
- Automated comment moderation using Hugging Face RoBERTa.

**Tech stack:** React, Node.js, TypeScript, MongoDB, AWS S3, Hugging Face (RoBERTa), and OpenAI API.
